# Blender Copy Keyframe Addon

A small Blender addon that makes it easier to copy keyframes to multiple objects without having to repeat the same process for each one.

The addon adds a simple tool to Blender's **N-Panel**, so you can copy animation data across multiple selected objects directly from the 3D Viewport.

## Why?

Blender's built-in keyframe tools work well, but copying the same animation across a bunch of objects can get repetitive.

This addon is meant to make that process quicker, especially for scenes where several objects need the same keyframes or animation timing.

## Features

- Copy keyframes to multiple objects at once
- Works directly from the Blender N-Panel
- Simple workflow without extra windows or complicated setup
- Useful for repeated or synchronized animations
- Lightweight Blender addon

## Installation

1. Download the repository as a ZIP:
   - Click **Code**
   - Click **Download ZIP**

2. Open Blender.

3. Go to:

   `Edit → Preferences → Add-ons`

4. Click **Install from Disk** and select the downloaded ZIP file.

5. Enable the addon.

After installation, the addon can be accessed from the **N-Panel** in the 3D Viewport.

Press `N` if the sidebar is hidden.

## Usage

1. Set up the keyframes you want to copy.
2. Select the objects you want to work with.
3. Open the **N-Panel** in the 3D Viewport.
4. Find the Copy Keyframe addon panel.
5. Use the copy keyframe controls to apply the animation to the selected objects.

The goal is basically to turn something that normally takes several repeated copy/paste operations into one step.

## Example

If you have ten objects that all need the same movement:

Instead of copying and pasting the animation onto every object individually, select the objects and use the addon to copy the keyframes across them together.

This can be useful for things like:

- repeated objects
- mechanical animations
- motion graphics
- synchronized movement
- quickly testing animation variations

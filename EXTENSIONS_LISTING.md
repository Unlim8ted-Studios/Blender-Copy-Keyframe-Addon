# Copy Keyframe to Selected Objects

Copy an animated property?s value at the current frame from the active object to selected objects.

**[Source code on GitHub](https://github.com/Unlim8ted-Studios/Blender-Copy-Keyframe-Addon)** ? [Report a bug](https://github.com/Unlim8ted-Studios/Blender-Copy-Keyframe-Addon/issues)

## Usage

Open the 3D Viewport sidebar (N), select the Tool tab, and find Copy Keyframe to Selected. Enter the property data path and array index, then run Copy Keyframe to Selected.

This version targets Blender 4.2?4.x. Blender 5.x is not supported.
